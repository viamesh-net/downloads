# ViaMesh downloads

Android offline installers for ViaMesh are available under [Releases](https://github.com/viamesh-net/downloads/releases).

Download options and setup information: [viamesh.net/app](https://viamesh.net/app/).

## Android offline installation

1. Download the APK while you have internet access.
2. Transfer it to your Android device, for example by USB, and open the file.
3. If Android asks, allow installation from the file manager or browser you used.

To update a direct APK installation, download a newer installer and install it over the existing app. Keep the app installed to preserve its data.

Each release includes a `SHA256SUMS` file to verify the download.
